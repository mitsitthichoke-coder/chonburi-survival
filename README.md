# ชลบุรี: วันล่มสลาย (Chonburi: Collapse)

เกมเอาชีวิตรอด 3D แบบ Open World ในจังหวัดชลบุรี ช่วงที่โลกกำลังเริ่มล่มสลาย เล่นคนเดียวหรือเล่นกับเพื่อนผ่านเครือข่ายได้
ทำด้วย **Three.js** (ฝั่งเบราว์เซอร์) และ **Node.js + WebSocket** (เซิร์ฟเวอร์สำหรับเล่นร่วมกัน)

## วิธีเล่น

```bash
npm install
npm start            # เปิดเซิร์ฟเวอร์ที่ http://localhost:8080
```

- **เล่นคนเดียว**: เปิด http://localhost:8080 แล้วกด "เล่นคนเดียว"
- **เล่นกับเพื่อน**: ให้ทุกคนเปิด `http://<IP ของเครื่องที่รันเซิร์ฟเวอร์>:8080` แล้วกด "เล่นกับเพื่อน"
  (ถ้าจะเล่นผ่านอินเทอร์เน็ต ใช้ ngrok / Cloudflare Tunnel หรือ deploy ขึ้น VPS แล้วใช้ `wss://`)
- ตั้งพอร์ตอื่นได้ด้วย `PORT=3000 npm start` ข้อมูลโลกเก็บไว้ที่ `data.json`
- **เล่นออนไลน์บนลิงก์ claude.ai (ไม่ต้องมีเซิร์ฟเวอร์)**: เมื่อเปิดเกมจากลิงก์ Artifact แล้วกด "เล่นกับเพื่อน" ทุกคนที่เปิดลิงก์เดียวกันจะอยู่ในโลกเดียวกัน
  - ผู้เล่นคนแรกจะเป็น "โฮสต์" ที่คำนวณผู้ติดเชื้อและข้อมูลโลก ถ้าโฮสต์ออก คนถัดไปรับช่วงต่ออัตโนมัติ
  - โลกถูกบันทึกในฐานข้อมูลของลิงก์นั้น
  - เจ้าของต้องแชร์ลิงก์ให้เพื่อนจากเมนู Share โดยให้สิทธิ์ **Contributor หรือ Editor** ถ้าได้สิทธิ์แค่ Viewer จะดูได้ แต่ส่งข้อมูลในห้องไม่ได้

| ปุ่ม | การทำงาน |
|---|---|
| WASD / Shift / Space | เดิน / วิ่ง / กระโดดหรือว่ายขึ้น |
| คลิกที่จอ + เมาส์ | หมุนกล้อง (ล้อเมาส์ = ซูม) |
| คลิกซ้าย หรือ F | โจมตี / ตัดไม้ / ทุบหิน / แทงปลา |
| E | โต้ตอบ: ค้นกล่อง, คุยกับคน, ตักน้ำ, ป้อนอาหารสัตว์, นอนในเพิง |
| 1–6 | ใช้ของในช่องลัด (กิน / ใช้ยา / ถืออาวุธ / วางสิ่งก่อสร้าง) |
| Tab / C · K · R · P · M | กระเป๋าและประดิษฐ์ · ตัวละคร · ความสัมพันธ์ · สัตว์เลี้ยง · แผนที่ |
| Enter | แชท |
| B / Q / X / L | เมนูสร้างบ้าน / หมุนชิ้นส่วน / โหมดรื้อ / ล็อกประตูหรือหีบ |
| 🔊 (มุมขวาบน) | เปิด/ปิดเสียง |

**บนมือถือ/แท็บเล็ต** (ถือแนวนอน): จอยสติ๊กซ้าย = เดิน · ลากนิ้วบนจอ = หมุนกล้อง · หยิกสองนิ้ว = ซูม · ⚔️ ตี/เก็บ (กดค้างได้) · ✋ โต้ตอบ · ⤒ กระโดด/ปีน · 🏃 วิ่ง (แตะเพื่อล็อก) · แถบปุ่มกลางจอเปิดเมนูต่างๆ
ถ้าอยากลองหน้าจอมือถือบนคอมพิวเตอร์ ให้เติม `?touch` ท้ายลิงก์

## ระบบในเกม (มีในต้นแบบนี้แล้ว)

### 🗺️ แผนที่จังหวัดชลบุรี
สร้างภูมิประเทศจาก**พิกัดละติจูด/ลองจิจูดจริง** (ย่อส่วน 1 หน่วย ≈ 50 เมตร พื้นที่ประมาณ 65×105 กม.)
- แนวชายฝั่งอ่าวไทย ตั้งแต่บางปะกงลงไปถึงสัตหีบ
- เมือง: เมืองชลบุรี, บางแสน (จุดเกิด), ศรีราชา, ท่าเรือแหลมฉบัง, บางละมุง, พัทยา (ตึกสูง), จอมเทียน, สัตหีบ, พนัสนิคม, บ้านบึง, สวนสัตว์เปิดเขาเขียว
- เกาะสีชัง, เกาะล้าน, เกาะสาก, เกาะคราม, เกาะไผ่ · เขาเขียว, เขาชีจรรย์ และเทือกเขาฝั่งตะวันออก
- แหล่งน้ำจืด: อ่างเก็บน้ำบางพระ, หนองค้อ, มาบประชัน · ถนนสุขุมวิทเลียบชายฝั่ง และรถร้างที่ค้นของได้

### 🍗 การเอาชีวิตรอด
- ค่าพลังชีวิต ความหิว ความกระหาย สตามิน่า และ % การติดเชื้อ
- น้ำทะเลดื่มไม่ได้ · น้ำจากอ่างต้องต้มที่กองไฟก่อน (ถ้าไม่ต้มอาจท้องเสีย) · ดื่มมะพร้าวหรือรองน้ำฝนได้
- อาการบาดเจ็บ: **เลือดออก** (รักษาด้วยผ้าพันแผล), **กระดูกหัก** จากการตกที่สูง (รักษาด้วยเฝือก), **อาหารเป็นพิษ** จากของดิบ
- **การติดเชื้อ**: ถ้าโดนผู้ติดเชื้อกัด เชื้อจะค่อยๆ ลุกลาม ถ้าถึง 100% จะเริ่มเสียพลังชีวิต รักษาด้วยยาสมุนไพร ยาปฏิชีวนะ หรือต้มยำสมุนไพร
- วัน/คืน (1 วัน = 12 นาที) กลางคืนผู้ติดเชื้อออกมามากและวิ่งเร็วขึ้น ยิ่งผ่านไปหลายวันโลกยิ่งอันตราย มีฝนตก และวิทยุกระจายข่าวเป็นระยะ
- ตายแล้วเกิดใหม่ที่เพิงพักของตัวเอง โดยของหายครึ่งหนึ่ง แต่ทักษะและความสัมพันธ์ยังอยู่

### 📜 ภารกิจหลัก: ตามหาศูนย์อพยพสัตหีบ
ดูได้ที่กล่องภารกิจด้านซ้าย ซึ่งมีลูกศรบอกทิศและระยะทาง และจะมี ⭐ บนแผนที่
1. หยิบวิทยุที่ป้อมยามชายหาดบางแสน
2. เตรียมอาวุธและน้ำต้มสุก 2 ขวด
3. ค้นรถร้างหาแบตเตอรี่
4. ส่งสัญญาณจากเสาส่งศรีราชา แล้วป้องกันเสาจากฝูงผู้ติดเชื้อ 60 วินาที
5. ทำความรู้จัก "แก้ว" ที่สัตหีบ เพื่อขอรหัสประตู
6. เปิดประตูค่ายอพยพ

ทำสำเร็จแล้วจะได้รางวัล และค่ายอพยพจะกลายเป็นเขตปลอดภัยและจุดเกิดใหม่ของคุณ

### 🧗 ปีนที่สูงหนีผู้ติดเชื้อ
- เดินชนกำแพงตึกแล้วกด Space (มือถือกด ⤒ หรือ ✋) เพื่อปีนขึ้นหลังคา การปีนใช้สตามิน่า ถ้าหมดแรงกลางทางจะร่วงลงมา
- เดินออกจากขอบหลังคาจะไต่ลงเองอย่างปลอดภัย แต่ถ้ากระโดดลงจากที่สูงอาจขาหัก
- ประดิษฐ์ **หอสังเกตการณ์** ไว้ปีนหนีในที่โล่งได้
- ผู้ติดเชื้อปีนไม่ได้ จะวนรออยู่ข้างล่าง และเลิกสนใจหลังประมาณ 15 วินาที

### 👕 เสื้อผ้าและกระเป๋า (ตัดเย็บเองได้)
มีช่องสวมใส่ 7 ช่อง ได้แก่ หมวก, เสื้อ, กางเกง/กระโปรง, ถุงมือ, ถุงเท้า, รองเท้า และกระเป๋า ดูและสวม/ถอดได้ที่เมนูตัวละคร (K) หรือคลิกเสื้อผ้าในกระเป๋า
- **วัตถุดิบ**: เศษผ้าขาด, ซิปและกระดุม, แผ่นเคฟลาร์ (หายาก) ดรอปจาก **ผู้ติดเชื้อ** และหนังสัตว์ได้จากหมูป่า/กวาง
- **22 สูตร** มี 4 ระดับตามทักษะ "ตัดเย็บ" เช่น
  - หมวกผ้า → หมวกกันน็อก → หมวกทหาร
  - เสื้อผ้าปะ → แจ็กเก็ตหนัง → เสื้อเกราะกันกระสุน
  - กางเกงผ้าปะ/ยีนส์/กางเกงทหาร หรือกระโปรงผ้าปะ/กระโปรงยาว
  - ถุงมือผ้า/หนัง, ถุงเท้า/ถุงเท้าหนา, รองเท้าแตะ/ผ้าใบ/บูท
- **ผลของเสื้อผ้า**: ลดความเสียหาย (สูงสุด 60%), ลดโอกาสติดเชื้อเมื่อถูกกัด (สูงสุด 70%), เดินเร็วขึ้น, สตามิน่าฟื้นเร็วขึ้น, ถุงมือทำให้เก็บของมือเปล่าแรงขึ้น
- เสื้อผ้าแสดงบนตัวละคร และเพื่อนที่เล่นออนไลน์เห็นด้วย
- **กระเป๋ามีเลเวล**:
  - ไม่มีกระเป๋า: 48 ช่อง
  - กระเป๋าผ้า Lv1: 56 ช่อง
  - กระเป๋าเป้เดินป่า Lv2: 72 ช่อง
  - กระเป๋าทหาร Lv3: 84 ช่อง
- **การนับช่อง**: ของชนิดเดียวกันซ้อนได้ 30 ชิ้นต่อช่อง (อาหาร/ยา 10, เครื่องมือ/เสื้อผ้า 1)
- ถ้าของเกินช่อง จะเดินช้าลง 40% และวิ่งไม่ได้ ทิ้งของได้ด้วยปุ่ม 🗑️ ในกระเป๋า หรือฝากไว้ในหีบ

### 🏠 สร้างบ้านทีละชิ้น (ออกแบบเองได้)
ต้องมี 🔨 ค้อนช่างไม้ก่อน แล้วกด **B** เพื่อเปิดเมนูสร้างบ้าน วิธีวาง:
- เลือกชิ้นส่วน → เงาสีเขียวคือวางได้ สีแดงคือวางไม่ได้ (มีบอกเหตุผล) → คลิกเพื่อวาง
- ทุกชิ้นวางบนกริด ช่องละ 3 หน่วย
- ผนัง รั้ว และประตูจะเกาะขอบช่องที่เล็งอยู่ให้อัตโนมัติ

ชิ้นส่วนที่มี:
- **โครงบ้าน**: ฐานราก, ผนัง, ผนังหน้าต่าง, ผนังประตู (เปิด/ปิดได้), หลังคา, บันได
  - ขึ้นไปยืนบนหลังคาแล้ววางผนังต่อ จะได้บ้าน **2 ชั้นขึ้นไป**
- **รั้ว**: รั้วไม้ และประตูรั้ว ผู้ติดเชื้อเดินทะลุรั้วและผนังไม่ได้
- **ของในบ้าน**: เตียง (ตั้งเป็นจุดเกิด), หีบเก็บของ (เพื่อนเปิดใช้ร่วมกันได้), บ้านสัตว์เลี้ยง
- **ล็อก**: กด L ที่ประตูหรือหีบ จะเปิดได้เฉพาะเจ้าของและคนที่มีความสัมพันธ์ระดับ "เพื่อน" ขึ้นไป
- **โหมดรื้อ (X)**: รื้อได้เฉพาะของตัวเอง และได้วัสดุคืนครึ่งหนึ่ง
- ทักษะใหม่ "ก่อสร้าง" จะเก่งขึ้นตามจำนวนชิ้นที่สร้าง

### 🌽 เพาะปลูก เลี้ยงไก่ เลี้ยงปลา
- **แปลงผัก**: ปลูกข้าวโพด ผักบุ้ง หรือฟ้าทะลายโจร
  - รดน้ำแล้วโตเร็วขึ้นประมาณ 3 เท่า และฝนจะรดน้ำให้เอง
  - เก็บเกี่ยวแล้วจะได้เมล็ดคืนด้วย
  - หาเมล็ดได้จากกล่องเสบียง
- **เล้าไก่**: มีแม่ไก่ 2 ตัว ให้อาหาร (ข้าวโพด/ผัก/ผลไม้ป่า) แล้วจะออกไข่ทุก 3 นาที นำไปทำไข่เจียวได้
- **บ่อเลี้ยงปลา**: ปล่อยปลาเป็นพันธุ์ ยิ่งมากยิ่งเพิ่มเร็ว ถ้าใส่ **ปลาทอง** ปลาจะเพิ่มเร็วขึ้น 2 เท่า ใช้เบ็ดตกในบ่อได้ด้วย
- เมนูอาหารใหม่: ข้าวโพดปิ้ง, ผัดผักบุ้งไฟแดง, ไข่เจียว, ปูนึ่ง, ปลาหมึกย่าง, กุ้งเผา, ปลากะพงเผาเกลือ

### 🎣 ตกปลา
ถือเบ็ดแล้วหันไปทางน้ำ → กด E หรือคลิกเพื่อเหวี่ยงเบ็ด → รอให้ทุ่นจม → กดให้ทัน
- ทะเล อ่างเก็บน้ำ และบ่อปลา ได้ปลาต่างกัน เช่น ปูม้า ปลาหมึก กุ้งก้ามกราม ปลากะพง และ 🐡 ปลาทอง (หายาก)
- ทักษะ "ตกปลา" ยิ่งสูง ปลายิ่งกินเบ็ดเร็ว และมีเวลากดนานขึ้น

### 🚲 ยานพาหนะ
- **จักรยาน**: เร็ว แต่ใช้สตามิน่า
- **มอเตอร์ไซค์**: เร็วมาก แต่ต้องเติมน้ำมัน ซึ่งหาได้จากรถร้างหรือกล่องเสบียง
- **แพไม้ไผ่**: ล่องทะเลไปเกาะสีชังหรือเกาะล้านได้
- กด E เพื่อขึ้น/ลง ใช้ W/S เร่งและถอย, A/D เลี้ยว
- ตอนเล่นออนไลน์ เพื่อนจะเห็นคุณขับอยู่

### 🏡 บ้านสัตว์เลี้ยง
สั่งสัตว์เลี้ยงให้อยู่บ้านได้จากเมนู 🐾 หรือที่บ้านสัตว์เลี้ยง สัตว์ที่อยู่บ้านจะฟื้นพลังชีวิต ความผูกพันไม่ลด และช่วยเฝ้าบ้านจากผู้ติดเชื้อ

### 🔊 เสียง
เสียงทั้งหมดสังเคราะห์สดในเบราว์เซอร์ ทั้งเสียงตี ตัดไม้ ทุบหิน กิน ดื่ม บาดเจ็บ ผู้ติดเชื้อคำราม (ได้ยินซ้ายขวาตามทิศ) สัตว์เลี้ยง และเลเวลอัป
มีเสียงบรรยากาศด้วย เช่น ลม คลื่นตอนอยู่ใกล้ทะเล ฝน กองไฟ และจิ้งหรีดตอนกลางคืน

### 🛠️ การประดิษฐ์
ขวานหิน, หอกไม้, มีดพร้า, กระบอกน้ำ, กองไฟ, เพิงพัก, เสื้อเกราะผ้า, แหวน, ผ้าพันแผล, เฝือก, ยาสมุนไพร, ยาปฏิชีวนะสกัด, น้ำต้มสุก, เนื้อย่าง, ปลาเผา, ต้มยำสมุนไพร
+ ชุดและอาวุธสำหรับสัตว์เลี้ยง และหอสังเกตการณ์
- **วัตถุดิบดิบ**: เก็บก้อนหินบนพื้น หรือทุบหิน/ถอนหญ้าด้วยมือเปล่า จะได้ "ก้อนหินดิบ" และ "ต้นหญ้าดิบ" ซึ่งต้องคราฟท์แปรรูปเป็นหิน/เส้นใยก่อน ถึงจะใช้เป็นวัตถุดิบได้ ถ้าใช้ขวานหรือมีดเก็บ จะได้ของพร้อมใช้เลย
- บางสูตรต้องอยู่ใกล้กองไฟ และต้องมีทักษะถึงระดับที่กำหนดก่อนถึงจะประดิษฐ์ได้

### ⭐ ตัวละครเก่งขึ้นตามประสบการณ์
มี 6 ทักษะ: เก็บเกี่ยว, ประดิษฐ์, ทำอาหาร, การแพทย์, การต่อสู้, เอาตัวรอด ซึ่งจะเก่งขึ้นจากการทำสิ่งนั้นจริงๆ
แต่ละทักษะมีผล เช่น ได้ของมากขึ้น ดาเมจสูงขึ้น ยาได้ผลดีขึ้น พลังชีวิตสูงสุดเพิ่มขึ้น และหิวช้าลง

### 💞 ความสัมพันธ์
**ไม่รู้จัก → คุ้นเคย → เพื่อน → เพื่อนสนิท → คนรัก → ครอบครัว**
- ความผูกพันเพิ่มขึ้นเมื่ออยู่ใกล้กัน พูดคุย ให้ของขวัญ (NPC แต่ละคนชอบของไม่เหมือนกัน) ทำแผลให้ หรือกอด
- เป็นคนรักได้ด้วยการ "สารภาพรัก" และเป็นครอบครัวได้ด้วยการ "ขอแต่งงาน" ด้วยแหวน **ซึ่งอีกฝ่ายต้องตอบตกลงเสมอ**
- ใช้ได้ทั้งกับเพื่อนที่เล่นออนไลน์ และกับ NPC ผู้รอดชีวิต 8 คนที่อยู่ตามเมืองต่างๆ (เช่น มะลิ พยาบาลที่บางแสน, บุญมี ชาวประมงศรีราชา)
- ถ้าเป็นคนรักหรือครอบครัวกันแล้วอยู่ใกล้กัน จะได้บัฟ "มีกำลังใจ" (สตามิน่าและพลังชีวิตฟื้นเร็วขึ้น) และ NPC ที่เป็นคนรักจะช่วยสู้ด้วย

### 👶 การตั้งครรภ์และลูก
- ตอนสร้างตัวละครเลือกบทบาทเป็นชายหรือหญิงได้
- คู่ชาย–หญิงที่เป็นคนรักหรือครอบครัวกัน เลือก "วางแผนมีลูก" ได้เมื่ออยู่ใกล้เพิงพัก และอีกฝ่ายต้องยินยอม
- ตอนตั้งครรภ์ (20 นาทีจริง) จะหิวเร็วขึ้น เดินช้าลง และสตามิน่าสูงสุดลดลง
- คู่ที่เป็นครอบครัวกันไม่ว่าจะเพศใด "รับเลี้ยงเด็กกำพร้า" ได้
- ลูกจะโตเป็นทารก (คนเลี้ยงอุ้มไว้) → เด็ก → วัยรุ่น ซึ่งช่วยหาของมาให้ทุก 2 นาที

### 🐾 สัตว์เลี้ยง
สุนัข แมว และนกขุนทองจรจัดจะอยู่ตามเมือง ถ้าป้อนอาหารที่มันชอบจนเชื่องครบ 100% ก็จะกลายเป็นสัตว์เลี้ยง
- **สเตตัส**: พลังชีวิต พลังโจมตี การลดดาเมจ ความผูกพัน และเลเวล (สูงสุด 20) ได้ XP จากการสู้ ให้อาหาร และเดินทางด้วยกัน
- **ความหายาก**: ธรรมดา / ✨ หายาก / 🌟 ตำนาน ยิ่งหายากยิ่งเก่ง และมีความสามารถพิเศษมากขึ้น (1–3 อย่าง) **สุ่มให้แต่ละตัวไม่เหมือนกัน**
  - 💗 หมอประจำตัว 🌿 นักหาของ 🐟 นักจับปลา 🛡️ ผู้พิทักษ์ 👃 จมูกไว 🔔 สัญญาณเตือนภัย
  - 🍀 นำโชค 🧪 นักสมุนไพร 🫶 ปลอบใจ 💨 ว่องไว 🔥 ใจกล้า 🦝 จอมแอบหยิบ
- **อาวุธ**: ปลอกคอหนาม, เล็บ/จะงอยเหล็ก
- **ชุด**: เสื้อเกราะสัตว์, ผ้าพันคอนำโชค, กระเป๋าสัมภาระ (ของที่หามาได้ ×2) ทุกชิ้นเห็นบนตัวสัตว์ด้วย
- ถ้าบาดเจ็บหนัก สัตว์เลี้ยงจะหมดสติแทนการตาย และฟื้นเองหรือใช้ผ้าพันแผลรักษาได้
- นอกจากนี้ยังมีความสามารถประจำชนิด
- 🐕 สุนัข: ช่วยกัดผู้ติดเชื้อ
- 🐈 แมว: คาบหนูมาให้ (ได้เนื้อ)
- 🐦 นกขุนทอง: บินสอดแนม ทำให้เห็นศัตรูและกล่องเสบียงบนแผนที่ย่อ
- สั่งให้ตามหรือรออยู่ที่เดิมได้ ต้องให้อาหารเพื่อรักษาความผูกพัน สัตว์เลี้ยงอาจถูกผู้ติดเชื้อฆ่าตาย และเพื่อนที่เล่นออนไลน์จะเห็นสัตว์เลี้ยงของเราด้วย

## 🌐 เรื่องการใช้ Google Earth
ใช้ภาพหรือโมเดลจาก Google Earth ในเกมโดยตรงไม่ได้ เพราะติดลิขสิทธิ์และข้อกำหนดการใช้งาน ต้นแบบนี้จึงสร้างภูมิประเทศจากพิกัดจริงแทน ถ้าอยากได้ความสมจริงระดับ Google Earth มีทางเลือกที่ถูกลิขสิทธิ์ดังนี้
1. **Google Photorealistic 3D Tiles** (Map Tiles API): ต้องมี API key และทำตามเงื่อนไขของ Google (ต้องแสดงเครดิต และห้ามเก็บข้อมูลไว้เอง) ใช้กับ `3d-tiles-renderer` หรือ CesiumJS ได้
2. **ข้อมูลเปิด**: ความสูงภูมิประเทศจาก SRTM / Copernicus DEM, อาคารและถนนจาก OpenStreetMap (ODbL) ซึ่งนำมาสร้างเป็นโลกในเกมได้ถาวร
3. ถ้าจะทำเป็นเกมเต็มรูปแบบ แนะนำให้ย้ายไปใช้ **Unreal Engine 5 + Cesium for Unreal** หรือ **Unity + Cesium**

## ข้อจำกัดของต้นแบบ และงานถัดไป
- **ตอนเล่นออนไลน์ทุกคนเห็นสิ่งเหล่านี้ร่วมกัน**:
  - ผู้ติดเชื้อ สัตว์ป่า สัตว์จรจัด และ NPC
  - บ้านทุกชิ้น ประตูที่เปิดหรือปิดอยู่ หีบเก็บของ แปลงผัก เล้าไก่ และบ่อปลา
  - ยานพาหนะ สัตว์เลี้ยงพร้อมชุด ฝนตก ความสัมพันธ์ และลูก
- สิ่งที่ยังแยกรายคน: ความคืบหน้าภารกิจหลัก ทุ่นตกปลา และพฤติกรรมของลูก (ตำแหน่งลูกคำนวณในเครื่องพ่อแม่)
- ตอนเล่นออนไลน์ ผู้ติดเชื้อยังไล่ทำร้ายแค่ผู้เล่น ไม่ทำร้ายสัตว์เลี้ยงหรือ NPC และ NPC ที่เป็นคนรักยังไม่ช่วยสู้
- ผู้ติดเชื้อยังพังผนังหรือรั้วไม่ได้ (ไอเดียต่อไป: ให้ผู้ติดเชื้อพังบ้านได้ ต้องซ่อมกำแพง)
- โมเดลตัวละครเป็นแบบ low-poly ทำเอง สามารถเปลี่ยนเป็นโมเดล glTF ที่มีแอนิเมชันได้ภายหลัง
- ไอเดียเพิ่มเติม: ปลูกพืช, ซ่อมเรือไปเกาะ, ฐานที่มั่นของกลุ่มผู้รอดชีวิต, เควสต์ตามหาศูนย์อพยพสัตหีบ, ภูมิคุ้มกันของลูก

## เปิดเซิร์ฟเวอร์สาธารณะ (ให้คนแปลกหน้าเข้าเล่น)

เซิร์ฟเวอร์ Node มีระบบสมัครด้วยอีเมล/ชื่อผู้ใช้/รหัสผ่าน เก็บตัวละครที่เซิร์ฟเวอร์ และกันโกง (ไอเท็มทุกชิ้นตรวจที่เซิร์ฟเวอร์)

### วิธีที่ 1: Render (ง่ายสุด)
1. เข้า https://render.com สมัครด้วยบัญชี GitHub
2. กด **New → Blueprint** แล้วเลือก repo `chonburi-survival` (ใช้ไฟล์ `render.yaml` อัตโนมัติ)
3. กด Apply แล้วเปิดแท็บ **Logs** ของ service จะเห็นกรอบ `🔑 รหัสยืนยันเจ้าของเซิร์ฟเวอร์: XXXXXXXXXXXX`
4. สมัครเข้าเกม แล้วพิมพ์ในแชท `/owner XXXXXXXXXXXX` เพื่อเป็น ⭐ เจ้าของ (รหัสใช้ได้ครั้งเดียว ห้ามบอกใคร)
5. ส่งลิงก์ให้เพื่อน: ลิงก์มีหน้าตาแบบ `https://chonburi-survival.onrender.com` ส่งให้เพื่อนเปิดได้เลย

> `render.yaml` ตั้งเป็น **แบบฟรี** ไว้ให้ทดลองก่อน ข้อเสียคือบัญชีและตัวละครจะหายเมื่อเซิร์ฟเวอร์รีสตาร์ต และเซิร์ฟเวอร์จะหลับเมื่อไม่มีคนเล่น 15 นาที (เปิดใหม่รอ ~1 นาที)
> พร้อมเปิดจริง: แก้ `plan: free` เป็น `plan: starter` และเอา `#` หน้าส่วน `disk:` ออก (ประมาณ 7 ดอลลาร์/เดือน) ข้อมูลจะเก็บถาวร

### วิธีที่ 2: Docker / VPS
```bash
docker build -t chonburi-survival .
docker run -d -p 8080:8080 -v $(pwd)/data:/var/data -e ADMIN_USERS=ชื่อของคุณ chonburi-survival
```
ควรตั้ง HTTPS ด้วย (เช่น Caddy หรือ Cloudflare) เพื่อให้รหัสผ่านถูกเข้ารหัสระหว่างทาง

### ตัวแปรที่ตั้งได้
| ตัวแปร | ค่าเริ่มต้น | ความหมาย |
|---|---|---|
| `PORT` | 8080 | พอร์ตเซิร์ฟเวอร์ |
| `DATA_DIR` | `./data` | ที่เก็บบัญชี ตัวละคร และโลก (ต้องเป็นดิสก์ถาวร) |
| `MAX_PLAYERS` | 40 | จำนวนผู้เล่นพร้อมกันสูงสุด |
| `ADMIN_USERS` | – | ชื่อผู้ใช้ที่เป็นเจ้าของ คั่นด้วย `,` (ไม่ต้องตั้งก็ได้ ใช้ `/owner รหัส` แทน) |
| `OWNER_KEY` | สุ่มให้ | กำหนดรหัสยืนยันเจ้าของเอง (ถ้าไม่ตั้ง ดูรหัสที่สุ่มใน Logs) |
| `ALLOWED_ORIGINS` | – | โดเมนอื่นที่อนุญาตให้เชื่อมต่อ WebSocket (ปกติไม่ต้องตั้ง) |

### ตั้งแอดมินในเกม
⭐ เจ้าของเซิร์ฟเวอร์ (คนที่ยืนยันด้วย `/owner รหัส`) พิมพ์ในแชท: `/admin ชื่อ` ตั้งแอดมินเพิ่ม · `/unadmin ชื่อ` ถอดแอดมิน · ทุกคนพิมพ์ `/admins` ดูรายชื่อแอดมินได้ (ใช้ชื่อตัวละครหรือชื่อผู้ใช้ก็ได้) · `/help` ดูคำสั่งทั้งหมด

### ระบบความปลอดภัย
- **กันยึดเจ้าของ:** สมัครก่อนไม่ได้เป็นเจ้าของ ต้องใช้รหัสลับจาก Logs (ใช้ได้ครั้งเดียว เดาผิดได้ 5 ครั้ง/ชั่วโมง และบันทึกทุกครั้งที่มีคนลอง) · ถอด/เตะ/แบนเจ้าของไม่ได้
- **รหัสผ่าน:** เก็บแบบ scrypt (ถอดกลับไม่ได้) · ใส่ผิด 8 ครั้งล็อกบัญชี 15 นาที · จำกัดการล็อกอิน/สมัครต่อ IP
- **ข้อมูลผู้เล่น:** ไม่มี API ให้ดูรายชื่อ/อีเมลคนอื่น อีเมลแสดงแบบปิดบัง (`a***@mail.com`) · ไฟล์ข้อมูลอยู่นอกโฟลเดอร์เว็บและอ่านได้เฉพาะเซิร์ฟเวอร์ (สิทธิ์ 600) · กันการเจาะ path เช่น `/../data/users.json`
- **กันโกง:** ไอเท็ม ดาเมจ ความเร็ว คำนวณ/ตรวจที่เซิร์ฟเวอร์ · จำกัดความถี่ข้อความ
- **เว็บ:** ห้ามเว็บอื่นฝังหน้าเกม (X-Frame-Options) · จำกัดแหล่งสคริปต์ (CSP) · รับ WebSocket เฉพาะจากหน้าเกมของเซิร์ฟเวอร์นี้
- โค้ดฝั่งเบราว์เซอร์ (หน้าเกม) ทุกเว็บดาวน์โหลดได้เป็นปกติ แต่ข้อมูลบัญชี/ตัวละคร/กฎการแจกของอยู่ที่เซิร์ฟเวอร์ทั้งหมด
