# ย้ายข้อมูลเกมไปเก็บที่ Neon (PostgreSQL)

เซิร์ฟเวอร์รองรับอยู่แล้ว (เวอร์ชัน 01.0007 ขึ้นไป): ถ้ามี env `DATABASE_URL` จะเก็บ บัญชี ตัวละคร และโลก ใน Postgres แทนไฟล์

## ขั้นตอน (ทำเองประมาณ 5 นาที)
1. สมัคร https://neon.com → สร้างโปรเจกต์ (เลือกภูมิภาคใกล้ที่สุด เช่น Singapore)
2. หน้า Dashboard → **Connection string** → คัดลอกค่าที่ขึ้นต้น `postgresql://...` (เลือกแบบ pooled หรือ direct ก็ได้)
3. Render → บริการเกม → **Environment** → เพิ่ม `DATABASE_URL` = ค่าที่คัดลอก → Save (เซิร์ฟเวอร์จะ deploy ใหม่เอง)
4. ดู Logs ต้องเห็นบรรทัด `🗄️ PostgreSQL ตัวเก็บข้อมูลพร้อมแล้ว`
5. (ถ้ามีข้อมูลเดิมที่อยากเก็บ) รัน `scripts/migrate-to-pg.mjs` **ก่อน** ขั้นตอนที่ 3 — ดูด้านล่าง

## ย้ายข้อมูลเดิม
บนเครื่องที่มีโฟลเดอร์ `data/` เดิม (ดาวน์โหลดจาก Render ได้ถ้าใช้ดิสก์ถาวร):
```
npm install
DATABASE_URL='postgresql://...' DATA_DIR=./data node scripts/migrate-to-pg.mjs
```
แพลนฟรีของ Render ไม่มีดิสก์ถาวร ข้อมูลเดิมจึงมักหายไปแล้วตอน deploy — ถ้าเป็นแบบนั้นข้ามขั้นนี้ได้

## ข้อควรระวัง
- ห้ามใส่ connection string ในโค้ด GitHub หรือส่งในแชท ถ้าหลุดให้ Reset password ใน Neon ทันที
- แพลนฟรีของ Neon: 0.5 GB และ 100 CU-ชั่วโมง/เดือน ดูหน้า Usage ของ Neon หลังใช้ 1–2 สัปดาห์
- ฐานข้อมูลหลับเองเมื่อไม่ใช้ 5 นาที (ตื่นอัตโนมัติ ใช้เวลาไม่กี่วินาทีตอนเชื่อมต่อครั้งแรก)
- เจ้าของเซิร์ฟเวอร์: รหัสยืนยัน `/owner` ยังเก็บเป็นไฟล์ในเครื่อง ถ้า Render รีสตาร์ตจะสุ่มรหัสใหม่ (ดูใน Logs) — บัญชีเจ้าของที่ยืนยันแล้วเก็บในฐานข้อมูล ไม่หาย
