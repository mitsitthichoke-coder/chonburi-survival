ชลบุรี: วันล่มสลาย

เกมเอาชีวิตรอด 3D โลกเปิด — แผนที่สร้างจากพิกัดจริงของจังหวัดชลบุรี ตั้งแต่บางแสน ศรีราชา พัทยา ถึงสัตหีบ

ขั้นตอน: ① สมัครด้วยอีเมลหรือเบอร์โทร + ชื่อผู้ใช้ + รหัสผ่าน → ② สร้างตัวละครครั้งแรก (ชื่อตัวละครห้ามซ้ำกับคนอื่น) → ③ เข้าเกม

👤

กด 🎲 สุ่มทั้งหมด หรือเลือกทีละส่วนด้านล่าง
เปิดเซิร์ฟเวอร์ด้วย npm start แล้วให้เพื่อนเข้า http://ไอพีของคุณ:8080
🌐 โหมดออนไลน์ในลิงก์นี้: ทุกคนที่เปิดลิงก์เดียวกันและกด "เล่นกับเพื่อน" จะอยู่ในโลกเดียวกัน (เจ้าของต้องแชร์ลิงก์ให้เพื่อนจากเมนู Share ก่อน)
